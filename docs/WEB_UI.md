# Веб-интерфейс: общие правила вида (web 1.61.0 – 1.64.3)

Сводка решений по оформлению, которые действуют на всех экранах. Подробности
экранов — в профильных спеках (ссылки ниже). История версий — `CHANGELOG.md`,
выкаты и откаты — `docs/DEPLOYMENT_STATE.md` §7я28–§7я40.

## Единые контролы

- Кнопки, селекты, «N / стр.», «Приоритет», вкладки настроек: высота 28px,
  радиус 6px, 0.8rem, фон `--surface-2` → `--border` при наведении/нажатии,
  рамка `--border`, `transition` 0.12s, один и тот же SVG-шеврон.
- Пейджер: «‹ ›» и размер страницы 25 / 50 / 100 / 250 (`PAGE_SIZES`, `ui.pageSize`;
  сохранённое значение приводится к ближайшему из списка).
- Кнопка «‹ К списку раздач» (1.62.0) вместо текстовой ссылки: `backButton()` /
  `navLink()` в `main.ts`, класс `.back-link`, стиль пейджера; шеврон сдвигается
  на 2px влево при наведении (reduced-motion — без сдвига). Стоит на карточке
  раздачи, «Сеть», «Ферма», «Кабинет», «Настройки».
- Фокус (1.64.2): синей обводки у селектов нет — Chrome/Safari считают клик и тап
  по `<select>` «видимым фокусом». Кольцо фокуса у селектов Кабинета/Настроек —
  нейтральное серое и только при навигации с клавиатуры: класс `html.kbd-nav`
  ставится на Tab/стрелках и снимается на любом `pointerdown`. У кнопок кольцо прежнее.
- Свои выпадающие списки (`enhanceSelect`, `.cselect-panel`) — только для мыши.
  На тач-устройствах (`pointerType` touch/pen, `touchstart`, либо `(pointer: coarse)`
  без `(any-pointer: fine)`) — только системный пикер (1.63.2).

## Графики «квадратиками» (`web/src/cellChart.ts`, 1.61.0)

- Общий рендер для «Истории» (`renderFarmChart`) и мини-графиков каналов
  (`renderMiniChart`, вкладки «Отдача», «Скачивание», «Всего отдано»).
- Чёткость: `viewBox` = размеру элемента, клетка и зазор кратны физическому пикселю
  (`round(n·dpr)/dpr`), сцена сдвигается на дробную долю пикселя (`alignCellStage`),
  клетки — отдельные `rect`.
- WAN1 — синий, WAN2 — зелёный; у низких колонок — бледные тона; «нет данных» —
  штриховка; пустые клетки бледно заполняют сетку.
- Анимация: при первой отрисовке и смене периода все колонки растут снизу вверх
  одновременно за 0.95 с (easeOutQuint, `growCells`); фоновое обновление меняет
  клетки на месте за 0.6 с (`morphCells`); reduced-motion — сразу итог.
- «История» опрашивает API раз в 30 с, пауза на скрытой вкладке, скелетон только
  на первой загрузке, ошибка фонового обновления оставляет прежний график,
  перекрывающиеся запросы и устаревшие ответы отбрасываются.
- Десктоп: клетка до 14px («История», минимум 10px) и до 8px (мини, минимум 5px).
- Телефон ≤ 640px (1.63.6): прокрутки вбок нет, клетка считается от ширины блока —
  минимум 4px («История») и 3px (мини), при слоте < 8px зазор 1px. На 390px:
  День (24 колонки) 8.3px, Неделя (28) 6.7px, Месяц (30) 6px. Подписи оси Y видны
  целиком, крайняя подпись X прижимается к краю, у «Недели» день подписан один раз;
  подсказка не выходит за карточку.
- Тач (1.64.4): тап — подсказка у столбика (над/под ним, зажим 8px в окне);
  скролл, жест прокрутки, тап вне графика, resize — скрывают. Мышь — за курсором.

## Телефон (≤ 640px, 1.63.0 – 1.63.5)

- Страница никогда не листается вбок (проверка: `scrollWidth` = ширине окна на
  360/390/414 и 768).
- Шапка переносится: заголовок своей строкой, аватар-меню справа в строке заголовка,
  кнопки ниже с переносом.
- Полоса статистики в шапке (1.63.3): шесть чипов сеткой 3×2 (28px, рамка, радиус 6px),
  всегда видны; «Обновлено …» — мелким текстом отдельной строкой; меню чипа — под ним
  (левая половина — по левому краю чипа, правая — по правому). См. `HEADER_STATS.md`.
- Вкладки «Сеть/Ферма» (1.63.4): сетка 3×2 без прокрутки, бегунок выделения ездит
  по `offsetLeft/Top` и между рядами.
- Поповеры и меню (Фильтры, Файл, + Торрент, сортировка, профиль, «…», «Скачать»,
  приоритет, трей): не шире `100vw − 16px`, при открытии сдвигаются в экран
  CSS-свойством `translate` с отступом 8px (1.63.1). «Файл» и «+ Торрент» открываются
  тапом: наведение — только для `pointerType === "mouse"`.
- Таблица файлов раздачи листается внутри своего блока, длинные имена переносятся.
- «Настройки → Лимиты» (1.63.5): строки движков и каналов одинаковые — имя и
  «своб. …» строкой, под ними ↓/↑ поровну и «ОК».
- Сетки карточек каналов: `minmax(min(22rem, 100%), 1fr)`; на планшете 561–820px строки
  движков компактные.

## Фон и тёмная тема

- После входа на всех экранах — мягкие пятна + сетка точек (1px через 18px)
  (`.page-mesh`, `.page-mesh-dots`, `body.page-mesh-on`), карточки — 86 %
  (`--glass-surface`), разделители над пейджером и подвалом — градиентная линия.
- Светлая тема: пятна бледные, точки 0.18, карточки белые 86 %.
- Тёмная тема (1.64.0; 1.64.1 ярче; 1.64.3 — середина между ними): тот же фон —
  слой 0.78, пятна синие/индиго/сланцевые (0.25–0.32), точки 0.19, карточки тёмные `rgba(24,24,27,.86)`, линия-разделитель
  светлая полупрозрачная. Графики в тёмной теме: пустые клетки светлые 6 %, сетка,
  оси, направляющая и подсветка колонки — под тёмный фон, бледные тона WAN1/WAN2 —
  тёмные синий/зелёный, подсказка тёмная с рамкой, бегунок вкладок `--surface-2` + рамка.
- Правила тёмной темы продублированы для явного выбора (`:root[data-theme="dark"]`)
  и системной (`@media (prefers-color-scheme: dark)` + `:root:not([data-theme="light"])`).
- Вход — «потоки данных» (`web/src/loginBg.ts`, canvas); в тёмной теме кривые и
  точки светлее, синий ярче. Цвета берутся при загрузке страницы. См. `LOGIN_SCREEN.md`.

## Кэш

`web/nginx.conf`: `index.html` и SPA-маршруты — `Cache-Control: no-cache`,
`/assets/` (с хешем в имени) — `public, max-age=31536000, immutable`.
Новая версия видна после обычного обновления страницы.
