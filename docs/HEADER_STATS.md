# Мини-меню статистики в шапке

> Внедрено. web **1.49.6.3** (чип кабинета снят в **1.51.2**). API и движки не трогаем.
> Экран «Сеть», куда ведут строки: [`NETWORK.md`](NETWORK.md).
> Карточка движка (только пункт «Движки»): `GET /api/v1/engines/{id}/info`.

Справа в шапке списка / детали / сети — одна плашка `.stats-dock`.
В покое видна только строка «Обновлено HH:MM:SS» с зелёной точкой.
По наведению цифры выезжают влево внутри плашки.

## Решения

| Тема | Решение |
|------|---------|
| Что свёрнуто | Шесть мини-меню: раздачи, объём, ↓, ↑, всего отдано, движки |
| Как открыть | Hover по плашке; клик по «Обновлено» ничего не закрепляет |
| Как закрыть | Увести курсор. Пока открыт `.tray.is-open` — не схлопывать |
| Анимация | `max-width` + opacity, ~0.29 с, `cubic-bezier(0.22, 1, 0.36, 1)` |
| Обрезка | Ряд якорится справа (`justify-content: flex-end`), overflow hidden, чтобы цифры не вылезали мимо профиля |
| Где нет дока | Настройки — только профиль. Кабинет — без чипа движков и без меню профиля |
| Вид выпадалки | Плотная плашка `var(--surface)`, 12px, без стекла/blur (как «Торрент» / профиль) |

## Куда ведёт строка движка

Раньше все шесть меню открывали одну карточку движка. Теперь у каждого своё:

| Меню | Клик по строке движка | Кнопка «ещё» в шапке меню |
|------|------------------------|---------------------------|
| Раздачи | список + фильтр `engine_id` | — |
| Объём | список + тот же фильтр + сорт `size` | — |
| Скачивание | `/network/download?engine={id}` | `/network/download` |
| Отдача | `/network?engine={id}` | `/network` |
| Всего отдано | `/network/uploaded?engine={id}` | `/network/uploaded` |
| Движки | модалка `showEngineDetailModal` | Настройки |

На «Сети» `?engine=` крутит к строке `.wan-eng[data-engine=…]` (`scrollIntoView`, без обводки).

`pushPath` сравнивает `pathname + search`, чтобы повторный клик на тот же URL не плодил историю.

## Поведение

```
.stats-dock
  .stats-dock__trays          max-width: 0 → 36rem по hover
    .stats-dock__trays-inner  width: max-content (цифры не сжимаются)
  .app-header__meta           «Обновлено …» + .live-dot 6×6 px
```

- Свёрнутая плашка не шире «Обновлено»; правый край совпадает с рядом кнопок.
- Выезд только внутри плашки, слева от времени. `overflow: visible` — лишь когда открыт tray-menu.
- Точка живая, круг 6×6, `flex: 0 0 6px`, не овал.

## Проверка

1. Ctrl+F5, в футере **v1.49.6.3**.
2. В покое справа только «Обновлено». Наведение — шесть цифр выезжают влево, не вылезают за профиль.
3. Увести курсор — плашка сама складывается. Клик по времени не держит её открытой.
4. Строка в «Отдача» / «Скачивание» / «Всего отдано» открывает «Сеть» на карточке этого движка.
5. Строка в «Раздачи» / «Объём» — список с фильтром движка.
6. Настройки: рядом с кабинетом нет чипа 9/9.
