# Плашка «Обновлено» и прокрутка страницы

Живые цифры сессии в шапке и плавный скролл окна. UI — vanilla TS + CSS,
анимация — Motion и Lenis (`web/package.json`).

## Плашка

В покое справа только точка и «Обновлено HH:MM:SS». Наведение выезжает
шесть чипов влево внутри той же подложки (раздачи, объём, ↓, ↑, всего
отдано, движки). Ширина выезда фиксируется по живым цифрам — подложка
не доезжает второй раз, пока числа крутятся.

Пока полоска едет, цифры мелькают случайные того же порядка. После
выезда пружина доводит их до актуальных. Дальше поток статистики
докручивает уже без сброса ширины.

Клик по чипу открывает меню движков: цифры в строках сразу финальные,
без счёта. «⋯» в «Раздачи» и «Объём» ведёт на `/farm` и `/farm/volume`.
На этих страницах и на Сети один компактный переключатель в шапке
справа: Раздачи / Объём / Скачивание / Отдача / Всего отдано / История.
Бегунок едет за наведением. Строка — в список, Сеть или карточку движка.

## Прокрутка страницы (web 1.53.56)

Страница крутится через [Lenis](https://github.com/darkroomengineering/lenis)
(`lerp` 0.12, колесо ×1.38): инерция есть, но быстрее, чем в 1.53.55.
Кнопка «Наверх» — `scrollTo(0)`.
Вложенные списки (поиск, селекты, меню, тело модалки) остаются нативными.
Пока открыта модалка, Lenis стоит. `prefers-reduced-motion` — без сглаживания.

Стек web: Vite 6 + TypeScript + Motion + Lenis. Сборка: `web/Dockerfile`
ставит зависимости из `package-lock.json`.
