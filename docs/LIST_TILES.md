# Виды списка

> Внедрено. web **1.51.2**. Переключатель: Плитка / Карточки / Мини таблица / Таблица.

## Плитка

Вариант 1 (имя целиком) + нижние кнопки из варианта 10 (иконки).

| Тема | Решение |
|------|---------|
| Имя | На всю ширину, 2 строки с многоточием |
| Статус / метка | Отдельный ряд под именем |
| Цифры | Три ячейки: прогресс·размер, ↑, пиры |
| Действия | Квадрат 2rem: пауза / старт / удалить. Подпись — `title` + скрытый текст |

## Карточки

Вариант 4 с канвы («Крупный процент»).

| Тема | Решение |
|------|---------|
| Прогресс | Крупная цифра слева + `%` |
| Отдача | Колонка ↑ и скорость слева от имени |
| Имя | Дальше справа, 2 строки с многоточием |
| Статус / метка | Текст под именем, без плашек |
| Действия | Меню ⋯: пауза / старт / удалить |
| Полоса / три кнопки | Нет — процент и меню вместо них |

## Мини таблица

Вариант 6 с канвы («Горизонтальная»).

| Тема | Решение |
|------|---------|
| Строка | Чекбокс · имя в одну строку · % · ↑ скорость · статус · ⋯ |
| Имя | Одна строка с многоточием |
| Действия | Меню ⋯: бейдж метки (в строке её нет), затем пауза / старт / удалить |
| Сетка | Одна колонка узких рядов, не широкая таблица |

## Общее

| Тема | Решение |
|------|---------|
| Таблица | Не меняется |
| Панель «Выбрано» | В плитке / карточках / мини таблице — два ряда. В таблице один ряд |

## Проверка

1. Ctrl+F5, футер **v1.51.2**.
2. Вид **Плитка**: имя в две строки; «Раздача» и метка ниже; три квадратные иконки.
3. Вид **Карточки**: процент, затем ↑ скорость, затем имя и статус·метка, справа ⋯ без бейджа.
4. Вид **Мини таблица**: строка имя · % · ↑ · статус · ⋯; в меню сверху бейдж метки.
5. Выделить раздачу: панель «Выбрано» не кривая. В таблице — по-прежнему одна строка.
