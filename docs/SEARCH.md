# Поиск в списке раздач

> Внедрено. web **1.53.24**, api **1.26.0**.
> Список после выбора: [`LIST_TILES.md`](LIST_TILES.md). Пружина: `web/src/motionPop.ts`.

Лупа в тулбаре — тот же кружок 2.4rem, что и соседние кнопки. Клик вытягивает
оболочку в строку (38→320px, Motion spring 0.58 / bounce 0.03). Под ней панель
подсказок. Синей обводки у фокуса нет; если есть запрос — акцент на оболочке.

## Решения

| Тема | Решение |
|------|---------|
| Пустая строка | История этого аккаунта (`localStorage` `ui.searchHistory.{name\|anon}`, до 12) |
| Ввод | Группы «сериал + сезон», не каждая раздача. Разбор: `web/src/searchTitle.ts` |
| Клик по группе | `q` = dotted префикс (`Title.s01`) — так `ILIKE` в API попадает в scene-имя |
| Enter / история | Тот же фильтр таблицы, панель закрывается |
| Крестик в поле | Стирает запрос и закрывает |
| Escape / фон | Закрывает, запрос остаётся |
| История | Крестик у строки + «Очистить историю» |

Подсказки: сразу из текущей страницы, затем `GET /torrents?q=&limit=80&sort=name`
(снимок БД, без обхода движков). Таблица перезагружается с паузой ~400 мс, не
на каждый символ.

Строки панели появляются каскадом на той же пружине. Стрелки по списку панель
не переигрывают.

## Проверка

1. Ctrl+F5, футер **v1.53.24**.
2. Клик по лупе — кружок тянется в поле, панель выезжает, не вспыхивает.
3. Пусто — история или «Здесь появятся недавние поиски».
4. Ввод сериала — одна строка сезона, не пачка качеств. Клик фильтрует список.
5. Крестик в поле чистит; Escape оставляет текст.
